# Hi-Fi Storefront Prototype — React + TanStack Start (青花瓷 edition)

Build a from-scratch hi-fi frontend prototype in `frontend/` (currently empty except AGENTS.md), per the answered scope: **full public storefront, mock data behind an API-shaped layer, both locales (en-US + zh-CN)**. Visual language: **Stripe-clean** (generous whitespace, crisp type, hairline borders, subtle shadows, angled gradient band) with a **blue-and-white porcelain (青花瓷) primary palette** and small SVG ornament decorations. Backend never runs; all data is typed mocks mirroring the Go DTOs.

## 1. Scaffold & stack (locked per `frontend/AGENTS.md`)

- Scaffold **TanStack Start** (React 19 + Vite, SSR) from the official starter into `frontend/`, then restructure to the AGENTS.md layout. Versions resolved at install time; `packageManager` pins pnpm 11.19.0.
- **Tailwind CSS v3.4** (not v4) + PostCSS + autoprefixer; **zod v3**; `@phosphor-icons/react`; `@radix-ui/react-dropdown-menu` (+dialog if the cart drawer needs it). `@fontsource-variable/inter` for type; zh falls back to system stack (PingFang SC / Microsoft YaHei / Noto Sans SC).
- `.env.example`: `VITE_API_MODE=mock|live`, `VITE_API_BASE_URL=http://localhost:1323`. Scripts: `dev`, `build`, `start`, `typecheck` (`tsc --noEmit`).

## 2. Design system — Stripe × 青花瓷

- `src/styles/tokens.css` — CSS variables: porcelain-cobalt scale (50–950, 600 = classic qinghua cobalt ~#3559AE family), ink text (~#101B33), porcelain white / Stripe-mist section tints, one restrained antique-gold accent (seal/stars only). Type scale, radius, layered soft shadows, container widths. Mapped through `tailwind.config.ts`.
- `src/components/ornaments/` — small, cobalt-only SVG decorations: wave-band (波涛纹) dividers, cloud-scroll (祥云) motif, lotus corner brackets, brush rule, and a **seal-stamp (印章) brand mark** — used sparingly (eyebrow markers, section dividers, hero watermark).
- `src/components/artwork/PorcelainFigure.tsx` — **procedural SVG imagery**: deterministic (seeded by product id) vase/bowl/plate/teapot silhouettes with generated qinghua patterns. Gives a coherent, self-contained visual identity for products/artists/destinations — no external image dependencies, fully SSR-able.

## 3. Core libs (contract-faithful)

- `lib/types.ts` — TS mirrors of the Go DTOs I read: `Product`(+SKUs, gallery, tags, alternates), `SKU`, `Cart`/`CartItem`, `Order`/`OrderItem`, `Artist`, `CeramicStory`, `Activity`, `ItineraryRequest`, `User`, `AuthResponse`, `PaginatedResponse<T>`. Money = minor-unit integers only.
- `lib/api.ts` — thin client over a Transport interface; **MockTransport** implements the API surface (router.go routes) with latency + the target envelope `{data, ...meta}` / `{error:{code,message,details}}`; typed `ApiError` keyed by **code** (snake_cased from `models/errors.go`: `not_found`, `invalid_credentials`, `2fa_required`, `cart_empty`, `unshippable`, `overweight`, `consent_required`, `too_many_attempts`, `conflict`…), surfaced via toast + inline + field layers. LiveTransport (fetch + Bearer + `/api` prefix) exists but is unused until `VITE_API_MODE=live`.
- `lib/money.ts` — `formatMinor` via `Intl.NumberFormat` on presentment values only; no FX/rounding math client-side (mock "server" does ECB+2%+rounding, incl. the PRD €183.47→€184 rule).
- `lib/i18n.tsx` — I18nProvider + `useI18n()`/`t()`; catalogs `src/i18n/en-US.ts` + `zh-CN.ts`; locale via `[locale]` URL segment (+cookie), toggle navigates to sibling path.
- `lib/auth.tsx` — token in localStorage, login → 2FA verify flow (demo super-admin triggers the 2FA step), guards redirect to login with `returnTo`.
- `lib/cart.tsx` — guest cart in localStorage, merge-on-login (demonstrates `POST /cart/merge`); totals always from the mock "server".

## 4. Mock dataset (`src/mocks/db.ts`)

~12 products with multi-SKU attribute sets (size/technique/glaze/edition/year/kiln per PRD §3.2.1, incl. one-of-a-kind stock=1), 5 artists, dynasty stories (ceramicstory), destinations + lifestyle (engage: Taoxichuan, Sanbao…), address book, orders across all 6 statuses, itineraries, a certificate with provenance records — **every content entity bilingual**. Mock FX table + per-country shipping tiers incl. one heavy SKU so checkout can demo the overweight block with the exact PRD message (en + zh).

## 5. Routes (file-based, `[locale]` public tree)

- `[locale]/__root.tsx` — locale validation/redirect, Header (nav, locale toggle, currency select, wishlist/cart badges, account menu), Footer, hreflang/canonical.
- `index` landing — hero (porcelain-white + faint wave texture), value-props trio, featured artworks, heritage editorial split, destinations, artists strip, **angled cobalt-gradient itinerary CTA band** (the Stripe signature).
- `catalog/index` — filter sidebar (tags/artist/edition/price) + sort, all in `validateSearch` zod params; `catalog/$slug` — gallery, SKU selector, add-to-cart/wishlist, artist cross-link, certificate seal, JSON-LD + meta from translation fields.
- `artists/`, `ceramicstory/` (dynasty timeline + article reader), `engage/` (+detail with styled map motif) — index + `$slug` each.
- `cart` (qty steppers, bulk remove, presentment summary), `checkout` (sign-in guard, address book + country → reactive shipping quote, Airwallex/PayPal sandbox UI, mandatory ToS/Privacy checkboxes, DDU text, overweight block) → order confirmation.
- `auth/login` (+2FA step), `auth/signup` (+consent checkboxes), `orders` list + `$id` detail (status timeline, tracking, cancel unpaid), `wishlist`, `itinerary` 4-step wizard (progress bar, the 8 launch interest chips, budget/pace/services/contact+consent, summary review, 24h-SLA acknowledgment; localStorage draft), `certificates/$code` (public QR-target page with provenance chain), `account/profile`.
